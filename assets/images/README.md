# Images Directory

Place your portfolio images here:

- `og-cover.jpg` — Social sharing image (1200×630px recommended)
- `your-photo.jpg` — Profile photo for the About section
- `project-*.jpg` — Screenshots of your projects (800×500px recommended)

## Image Guidelines

- Use `.jpg` or `.webp` for photos and screenshots
- Use `.png` for images with transparency
- Optimize images before adding them (use tools like TinyPNG or Squoosh)
- Recommended project screenshot size: 800×500px
- Recommended profile photo size: 560×680px
- Recommended OG cover size: 1200×630px
